📌 候选提示词 · 使用指南

钉在屏幕最前面的 AI 提示词暂存工具：想到下一步任务，先写在这里，要用时点一下复制。

开始使用

解压整个压缩包
→
打开文件夹
→
双击 候选提示词.exe
→
开始使用
⚠️ 若弹出「Windows 已保护你的电脑」：点 更多信息 → 仍要运行（仅首次）。
💡 建议：右键 exe → 发送到 → 桌面快捷方式。不要把 exe 单独拖出文件夹。

不用时折叠起来

点一下顶栏空白处，整个窗口会收成一条（只剩一行待办条数，宽度不变）；再点这条任意位置展开。折叠状态会记住，下次打开还是收起来的。

两个板块

顶栏中间的 提示词 | 待办 切换。待办板块按时间管理四象限分类（重要且紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急，可改名）：点击整条即可编辑，右侧对勾键打勾会给文字划线但不删除，日期标签点一下弹日历、逾期会标红。排序、折叠、删除和提示词板块一样。

提示词板块速览

写提示词底部输入框，点「添加」或 Ctrl+Enter
用提示词点卡片正文 → 已复制，去 AI 对话框粘贴即可
排序按住卡片左侧把手 ⠿ 上下拖动，拖到边缘会自动滚动
折叠卡片左下角 ▾ 折叠成一行，再点 ▸ 展开
分组左上角下拉菜单：切换 / 改名 / 删除 / 新建
卡片按钮铅笔 编辑 · 星标 收藏（实心为已收藏，再点取消）· 叉号 删除
右上角星标 收藏区 · 回收站（删除的保留 7 天可恢复）· 图钉 置顶开关 · 太阳/月亮 主题

数据在哪

所有内容自动保存在本机：%APPDATA%\prompt-stash\prompts-data.json，备份拷这一个文件即可。
