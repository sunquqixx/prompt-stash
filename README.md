# 📌 候选提示词（Prompt Stash）

一个钉在屏幕最前面的小工具（macOS / Windows），两个板块：**AI 提示词暂存** 和 **四象限待办**。

> 和 AI 结对干活时，你脑子里常常已经想好了它「下一步」要干的任务——但当前任务还没跑完，这个念头没地方放。把它写进这个始终置顶的小窗口，要用时点一下：复制、粘贴、发送。

## 它解决什么问题

和 Claude Code、ChatGPT 这类 AI 的对话是「串行」的：AI 跑当前任务时，你想到的下一步只能记在脑子里、备忘录里、或者聊天框草稿里——切换几次应用就丢了。

这个工具给你一个**永远浮在最前面**的小窗口（切换桌面、台前调度切换应用都不会被盖住），专门暂存「下一条要发给 AI 的提示词」：

- 按会话/项目**分组**（比如「Claude Code」「Hermes」各一组，列表和草稿互不干扰）
- 点一下卡片正文即**复制到剪贴板**，粘到 AI 对话框就能发
- 写得好的提示词一键**收藏**，跨分组沉淀复用
- 删错了有**回收站**兜底（保留 7 天）

顶栏中间的 `提示词 | 待办` 可以切换两个板块，它们共用同一个窗口框架，各自独立。

不用的时候点一下顶栏空白处，整个窗口会**折叠成一条**（只剩一行待办条数），再点一下展开。

## 功能一览

### 提示词板块

| 操作 | 方式 |
|---|---|
| 写提示词 | 底部输入框，`⌘/Ctrl+Enter` 或点「添加」；每个分组的草稿各自独立 |
| 用提示词 | 点卡片正文 → 已复制，去粘贴即用；用完的自己 `✕` 删掉 |
| 排序 | 按住卡片左侧把手 `⠿` 上下拖动；拖到列表边缘会自动滚动，`Esc` 取消本次拖动 |
| 折叠 | 卡片左下角 `▾/▸` 折叠成一行，长提示词可压到原高度的 ~20%；折叠状态记住不丢 |
| 编辑 | 卡片铅笔键原地改，`⌘/Ctrl+Enter` 保存，`Esc` 取消 |
| 收藏 | 卡片星标（实心金色为已收藏，再点取消）；顶栏星标进收藏区 |
| 分组 | 左上角下拉菜单：点击切换；悬停可改名、删除；底部「＋ 新建分组」 |
| 回收站 | 顶栏回收站图标；删除的提示词/收藏保留 7 天，一键恢复到原处 |
| 置顶开关 | 顶栏图钉（含跨桌面 / 台前调度可见性） |
| 主题 | 顶栏太阳/月亮切换白天黑夜；深色主题下强调色为白，浅色主题为蓝 |

### 待办板块

按**时间管理四象限**分类，固定 4 组（可以改名，不能删除或新增）：重要且紧急 / 重要不紧急 / 紧急不重要 / 不重要不紧急。下拉菜单里每个象限后面显示未完成条数。

| 操作 | 方式 |
|---|---|
| 写待办 | 底部输入框，`⌘/Ctrl+Enter` 或点「添加」 |
| 编辑 | **点击整条**即可原地编辑（这里没有单独的编辑键） |
| 完成 | 右侧对勾键，文字加删除线并调淡；条目**留在原位不删除**，再点取消 |
| 到期日 | 卡片右侧日期标签，点一下弹小日历——**打开就停在当月，点一下日子即可**；带「今天 / 明天 / 清除」快捷键，`‹ ›` 换月。逾期红 / 今天橙 / 三天内黄 / 更远灰 |
| 排序 · 折叠 · 删除 | 与提示词板块一致（折叠时只保留对勾键，卡片压到一行） |
| 改象限名 | 下拉菜单里悬停某个象限 → 铅笔键 |

### 折叠整个窗口（两个板块通用）

不用的时候点一下**顶栏空白处**，窗口收成一条：约 31px 高、宽度不变，条上只显示 `5 条待发送 · 3 条待办`——待发送数的是各分组里的全部条数（不含收藏夹），待办数的是未完成的；某一项为 0 就不显示那半句，都清空时显示「都处理完了」。点这条**任意位置**展开，恢复到折叠前的高度。

折叠状态会记住——下次打开直接就是收起来的那条，且窗口等尺寸就位后才显示，不会先闪一下大窗口。

所有状态（分组、象限名、顺序、折叠、窗口折叠、提示词、待办、完成、到期日、收藏、回收站、置顶、主题、上次所在板块）都在本地持久化，重启不丢。

## 快速开始

### Windows

到 [Releases](../../releases) 下载 `PromptStash-Windows.zip`，解压后双击 `候选提示词.exe`——免安装绿色版。首次运行若提示「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。压缩包内附一页纸 `使用指南.html`。

### macOS（从源码运行）

```bash
git clone https://github.com/sunquqixx/prompt-stash.git
cd prompt-stash
npm install
npm start
```

Electron 下载慢时用镜像：`ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm install`

可选：生成一个双击即开的启动器（生成后可拖到 Dock 或「应用程序」）：

```bash
osacompile -o 候选提示词.app -e "do shell script \"nohup '$PWD/node_modules/electron/dist/Electron.app/Contents/MacOS/Electron' '$PWD' >/dev/null 2>&1 &\""
```

## 数据存哪

一个 JSON 文件，完全本地运行、不联网、无账号：

- macOS：`~/Library/Application Support/prompt-stash/prompts-data.json`
- Windows：`%APPDATA%\prompt-stash\prompts-data.json`

备份 = 拷走这一个文件。

## 技术说明

Electron + 原生 HTML/CSS/JavaScript（零前端框架、零运行时依赖），3 个源文件约 1593 行：

| 文件 | 职责 |
|---|---|
| `main.js` | 主进程：窗口与置顶（`screen-saver` 层级 + 跨 Spaces 可见）、窗口折叠时的尺寸控制、数据文件读写、剪贴板、单实例锁 |
| `preload.js` | contextBridge 安全桥：界面只能调用「读数据 / 存数据 / 复制 / 置顶 / 改窗口高度 / 就绪通知」这几个白名单能力 |
| `index.html` | 全部界面与交互逻辑，单文件（含自绘拖动排序、内联 SVG 图标）|

拖动排序是自己实现的，没有用浏览器原生 drag-and-drop：原生拖拽会把文字带出窗口，而这是个 380px 宽、永远置顶的小窗，拖出边界松手就等于往下层的 AI 对话框里粘贴一段文字。指针事件监听挂在 `window` 上而非把手元素上——换位时卡片要从 DOM 摘下再插回，那会让 `setPointerCapture` 失效，鼠标一离开把手就收不到事件。图标用内联 SVG 而非字符，是为了 macOS 与 Windows 上粗细完全一致。

本项目由 [Claude Code](https://claude.com/claude-code) 结对完成——从需求对齐到 MVP 可用不到一天，之后按使用反馈逐条迭代。而它服务的，恰好就是这种和 AI 结对的工作流。
